# Installation

1. Download or clone this repository.
2. Create `~/.codex/pets/xiaoxing/`.
3. Copy `pet/pet.json` and `pet/spritesheet.webp` into that directory.
4. Restart Codex if needed.

```bash
git clone <repository-url>
cd xiaoxing-codex-pet
mkdir -p ~/.codex/pets/xiaoxing
cp pet/pet.json pet/spritesheet.webp ~/.codex/pets/xiaoxing/
```
